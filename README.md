# unit-converter

Переводит числа между единицами измерения: длина, масса, температура, объём,
скорость, площадь, время, давление, энергия, мощность, объём данных, углы.
Больше ничего не делает.

* Модель: `openai:gpt-5.5` через OpenAI-совместимый шлюз
* Стандарт: LangChain v1 `create_agent`
* Памяти нет: ни сессий, ни долговременной. Каждое сообщение обрабатывается
  независимо, чекпоинтер не подключается, `MONGODB_URI` не читается.

## Запуск

```bash
cp .env.example .env      # и заполнить LLM_API_KEY и LLM_BASE_URL
python main.py "12 км в милях"
```

В контейнере точка входа — `bot.py` (Telegram-бот, long polling).

## Структура

| Файл | Что внутри |
|---|---|
| `agent.py` | `build_agent()` — сборка агента, системный промпт |
| `config.py` | `AgentConfig` — модель и лимиты из окружения |
| `tools/convert.py` | таблицы единиц, `convert_units`, `list_units` |
| `tools/__init__.py` | реестр `TOOLS` |
| `middleware/` | ретраи, human-in-the-loop |
| `schemas.py` | pydantic-модель структурированного ответа (не подключена) |
| `main.py` | CLI |
| `bot.py` | Telegram-бот для контейнера |
| `tests/` | смоук-тесты и проверка таблиц пересчёта |
| `agent.json` | манифест для деплоя |

## Как добавить единицу измерения

1. Открыть `tools/convert.py`.
2. В нужную категорию `_LINEAR` добавить строку
   `"канон": (коэффициент_к_базовой_единице, ("синоним", ...))`.
3. Прогнать `agent_test` — таблицы покрыты параметризованными тестами.
